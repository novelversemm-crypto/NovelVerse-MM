စူဝမ်ယန် (Su Wanyan) တစ်ယောက် ရိုက်ကူးရေးကား၏ နောက်ဖုံးထိုင်ခုံပေါ်မှာ အေးဆေးစွာ ဝင်ထိုင်နေခဲ့တယ်။ အနီးနားမှာ တပ်ဆင်ထားတဲ့ ကင်မရာက သူမ မျက်နှာပေါ်က အမူအယာ အပြောင်းအလဲ တိုင်းကို အသေးစိတ် ရိုက်ကူးနေခဲ့တာပါ။ အနီးကပ် ကြည့်လိုက်ရင် သူမ၏ အသားအရေက ဘာပြစ်ချက်မှ မရှိဘဲ ချောမောပြောင်လက်နေတဲ့ ကျောက်စိမ်းတုံးလေးအတိုင်း တောက်ပနေခဲ့တယ် - သဘာဝအတိုင်း ဝင်းပနေတဲ့ အလင်းရောင်က ထိုးဖောက်ဝင်ရောက်လာတဲ့ နေရောင်ခြည်နဲ့ ပေါင်းစပ်သွားရာ မရှိသင့်လောက်အောင် လှပနေခဲ့ရတယ်။
လိုက်ဖ်ကြည့်နေတဲ့ ပရိသတ်တွေကတော့ အံ့ဩချီးကျူးမှု၊ နှမြောတသဖြစ်မှုတွေနဲ့ စာတန်းတွေ ဆက်တိုက် ရေးသားနေကြတယ်။
[အစီအစဉ် ပြီးသွားရင် ဒီမျက်နှာလေးကို တကယ် သတိရနေတော့မှာပဲ...]
[အနုပညာလောကထဲ မဝင်ခဲ့တာ တကယ် နှမြောစရာပဲနော်။]
[ဟုတ်တယ်၊ ဒါပေမဲ့ သူ ကယ်တင်ခဲ့တဲ့ ကလေးငယ်လေးတွေကို စဉ်းစားကြည့်လေ။ အဲဒါက ပိုပြီး တန်ဖိုးရှိပါတယ်။]
[အမှန်ပဲ။ လေးစားပါတယ်။]
စူဝမ်ယန်ကတော့ မှတ်ချက်တွေကို အာရုံမရောက်ဘဲ စိတ်ထဲမှာပဲ အာရုံစိုက်ထားခဲ့တယ်။ သူမ အမြင်အာရုံမှာ အိတ်ဇာတ် စခရင်ကွင်းလေး ခပ်မှိန်မှိန် ပေါ်နေပြီး တောက်ပနေတဲ့ ရွှေရောင် လက်မှတ် ၆ စောင်က ဖိတ်ခေါ်နေသလိုပါပဲ။
*(ဒါတွေက ဘာတွေလဲ၊ ကံစမ်းမဲ လက်မှတ်တွေများလား... ဂိမ်းတွေထဲကလိုမျိုးပေါ့)*
စိတ္တဇစိတ်က အနိုင်ရသွားတာမို့ တစ်စောင်ကို စမ်းသုံးကြည့်ဖို့ အာရုံစိုက်လိုက်တယ်။
အဲဒီနောက် ခပ်တိုးတိုး စာတန်းလေး ပေါ်လာခဲ့တယ်။
< လက်မှတ် ၆ စောင်လုံး အသုံးပြုမလား >
*(အသုံးပြုမယ်)* လို့ စိတ်ထဲကနေ သေချာစွာ ဖြေလိုက်တယ်။
သူမ အမြင်အာရုံထဲမှာ ကြီးမားလှပတဲ့ မဲနှိုက်စက် ဝိုင်းကြီး ပေါ်ထွက်လာခဲ့တယ် - အဆန်းတကြယ် ထုဆစ်ထားပြီး အပိုင်းအခြားတွေက လျင်မြန်စွာ လည်ပတ်သွားခဲ့တယ်။ တဖြည်းဖြည်း မီးတောက်တွေ နှေးကွေးသွားပြီး ရင်ခုန်စရာ အချိန်အဖြစ် ပြောင်းလဲသွားကာ၊ သာယာတဲ့ အသံလေးနဲ့အတူ ရပ်တန့်သွားခဲ့တယ်။ ရွှေရောင် အလင်းတန်းတွေ နွေးထွေးစွာ လင်းလက်သွားပြီးမှ ဆုကြေးက ပေါ်ထွက်လာခဲ့တော့တယ်။
{ လက်နက်အပေါ် စိုးမိုးနိုင်စွမ်း (Arms Sovereignty) -
လက်နက်အားလုံးကို ပြည့်စုံစွာ ထိန်းချုပ်နိုင်စွမ်း ပေးအပ်မည်။ အလေးချိန် နားလည်မှုက ဟန်ချက်ကို ချိန်ညှိပေးမည်၊ လှုပ်ရှားမှု ကြိုတင်ခန့်မှန်းမှုက ရန်သူကို အကဲခတ်နိုင်မည်၊ အလိုက်သင့် အုပ်ကိုင်မှုက ထိန်းချုပ်မှုကို သေချာစေမည်၊ ရိုက်ခတ်မှု အကောင်းဆုံးဖြစ်အောင် ပြုလုပ်ခြင်းက ထိရောက်မှုကို မြှင့်တင်ပေးမည်ဖြစ်ပြီး၊ လက်နက် ဟာမိုနီဖြစ်မှုက လက်နက်မျိုးစုံကို လိုက်လျောညီထွေ သုံးစွဲနိုင်မည်။ လက်နက်များသည် ခန္ဓာကိုယ်၏ အစိတ်အပိုင်းအဖြစ် ပြောင်းလဲသွားမည်။ လက်နက်အဖြစ် ရှုမြင်နိုင်သော အရာအားလုံးတွင် အကျိုးသက်ရောက်မည်။ }
စူဝမ်ယန် မျက်လုံးများ ကျယ်သွားခဲ့ရတယ်။ *(ဒါကတော့ လုံးဝ ပိုလွန်းလှတဲ့ စွမ်းရည်ပဲ။ ငါ လက်နက်လို့ ယူဆသမျှ အရာတိုင်းမှာ အကျိုးသက်ရောက်မှာ ဟုတ်လား... ဘောပင်ဆိုရင်ရော။ နောက်မှ စမ်းကြည့်ရမယ်)*
သူမ မဆိုင်းမတွဘဲ ပြန်လှည့်လိုက်တယ်။ *(ထပ်မဲနှိုက်မယ်)*
ဒိုင်းကြီးက ထပ်မံ လည်ပတ်သွားပြီး အရောင်အသွေးတွေ ဝှေ့ဝဲသွားခဲ့တယ်။ ချောမောစွာ နှေးကွေးသွားပြီး ရွှေရောင် အလင်းတန်းများ ထပ်မံ ပေါ်ထွက်လာကာ နောက်ထပ် စွမ်းရည်တစ်ခု ပေါ်လာခဲ့ပြန်တယ်။
{ စီးဆင်းနေသော သံမဏိ (Flowing Steel) -
ခန္ဓာကိုယ်၊ စိတ်ဓာတ်နှင့် တိုက်ခိုက်ရေး ဗီဇတို့၏ ပြည့်စုံသော ပေါင်းစပ်မှုကို ပေးအပ်မည်။ ပုံသဏ္ဍာန်မဲ့ ထိုးနှက်ချက်က ရန်သူနှင့် အလိုက်သင့် ပြောင်းလဲမည်၊ သံမဏိစိတ်ဓာတ် ဟန်ပန်က ဟန်ချက်ကို တည်ငြိမ်စေမည်၊ လှုပ်ရှားမှု ရိုက်ခတ်သံက ရန်သူ့ ရည်ရွယ်ချက်ကို ကြိုတင်ခန့်မှန်းပေးမည်၊ သွေးခုန်နှုန်း တိုက်ကွက်က ထိန်းချုပ်ထားသော စွမ်းအားကို ပေးစွမ်းမည်ဖြစ်ပြီး၊ အစောင့်အရှောက် စီးဆင်းမှုက အပေါင်းအဖော်များကို ကာကွယ်ပေးမည်။ လှုပ်ရှားမှုတိုင်းသည် ပြေပြစ်မည်၊ တိကျမည်ဖြစ်ပြီး ဗီဇအတိုင်း အန္တရာယ်ရှိနေမည်။ }
နောက်ထပ် သန်မာတဲ့ စွမ်းရည်တစ်ခုပါပဲ။ သူမ ကျောပြင်ထဲမှာ အေးစိမ့်သွားရတယ်။ ဒီလို တိုက်ခိုက်ရေး စွမ်းရည်တွေ ရလာတာက တစ်နေ့နေ့မှာ ဒါတွေကို သုံးရတော့မလိုလို နိမိတ်ပြနေသလိုပါပဲ။ ဒါပေမဲ့ အသုံးဝင်ပါတယ်။ သူမရော မူလပိုင်ရှင်ရော ဘာ ကိုယ်ခံပညာမှ မတတ်ခဲ့တာမို့ ဒါက တကယ်ပဲ အသက်ကယ်ပေးနိုင်ပါလိမ့်မယ်။
အခုတော့ ရင်ခုန်စိတ်လှုပ်ရှားမှုတွေ ဝဲပျံလာခဲ့ပြီ။ *(မဲနှိုက်မယ်)*
ဒိုင်းကြီး လည်ပတ်သွားတယ်၊ နှေးသွားတယ်၊ လင်းလက်သွားခဲ့တယ်။
{ စိုက်ပျိုးရေးနှင့် ချက်ပြုတ်ရေး ဝိဇ္ဇာ (Culinary Alchemy) -
ပါဝင်ပစ္စည်းများ၊ အရသာနှင့် အချိန်အခါတို့အပေါ် ဗီဇအတိုင်း ထိန်းချုပ်နိုင်စွမ်း ပေးအပ်မည်။ အရသာ မျှတစေခြင်းက အရသာကို ဟန်ချက်ညီစေမည်၊ အပူချိန် တိကျမှုက ချက်ပြုတ်မှုကို ပြည့်စုံစေမည်၊ ပါဝင်ပစ္စည်း အကဲခတ်မှုက လတ်ဆတ်မှုကို ခွဲခြားပေးမည်၊ ဖန်တီးမှု ပေါင်းစပ်ခြင်းက အစားအသောက်များကို ဆန်းကြယ်စွာ သို့မဟုတ် ကျန်းမာရေးနှင့် ညီညွတ်စွာ တိုးတက်စေမည်ဖြစ်ပြီး၊ ပြင်ဆင်မှု ကျွမ်းကျင်ခြင်းက အမြင်နှင့် စိတ်ခံစားမှု ဆွဲဆောင်မှုကို သေချာစေမည်။ ဟင်းလျာတိုင်းသည် ခန္ဓာကိုယ်နှင့် ဝိညာဉ်ကို အာဟာရ ပေးစွမ်းလိမ့်မည်။ }
သူမ နူးညံ့စွာ ပြုံးလိုက်မိတယ်။ အစားအသောက် ချက်ပြုတ်ရတာက သူမအတွက် အမြဲတမ်း ပျော်ရွှင်မှု အသေးလေးတစ်ခု ဖြစ်ခဲ့တာပါ - မောပန်းတဲ့ ညတွေမှာ အိမ်ချက် အရသာလေးတွေနဲ့ စိတ်ကို အနားပေးခဲ့ရတာလေ။ ဒီစွမ်းရည်က သာမန်အရသာကို ထူးခြားဆန်းပြား သွားစေမှာပါ။ အစီအစဉ်ရဲ့ ထမင်းဟင်းတွေအတွက်လည်း အပြည့်အဝ အဆင်ပြေသွားခဲ့ပြီ။
တစ်စောင်ပြီးတစ်စောင် နှိုက်လိုက်ရာ ရင်ခုန်မှုတွေက ပိုမို မြင့်တက်လာခဲ့တယ်။
{ စိမ်းလန်းသော အထိန်းအကွပ် (Verdant Stewardship) -
အသုံးပြုသူကို မြေဆီလွှာ၊ သီးနှံများနှင့် မွေးမြူရေး တိရစ္ဆာန်များနှင့် ချက်ချင်း ဆက်သွယ်ပေးမည်။ အမြစ်သံ တိုးတိုးက အာဟာရနှင့် အားနည်းချက်များကို သိရှိစေမည်၊ ရာသီဥတု ကြိုတင်ခန့်မှန်းမှုက မိုးလေဝသနှင့် ကြီးထွားမှုကို ခန့်မှန်းပေးမည်၊ ကြီးထွားမှု ဟာမိုနီဖြစ်မှုက အပင်၏ စွမ်းရည်ကို အမြင့်ဆုံး ဖြစ်စေမည်ဖြစ်ပြီး၊ တိရစ္ဆာန် ဆက်ဆံရေးက မွေးမြူရေး တိရစ္ဆာန်များနှင့် မသိမသာ ဆက်သွယ်ပေးမည်။ အသုံးပြုသူသည် စိုက်ပျိုးရေး၏ အသက်ဝင်သော ပြယုဂ်ဖြစ်လာမည်။ }
သူမ ရင်ခုန်သံ မြန်သွားခဲ့ရတယ်။ အစီအစဉ်ရဲ့ နောက်ပိုင်း အပိုင်းတွေမှာ ဝေးလံတဲ့ ကျေးရွာဆီ ပြောင်းရွှေ့ပြီး ကိုယ်ပိုင် အစားအသောက်တွေကို စိုက်ပျိုးရမှာလေ။ ဒီစွမ်းရည်က အဲဒီအတွက် တိကျစွာ ပြုလုပ်ထားသလိုပါပဲ။ *(ကျေးဇူးပါပဲ၊ လူမှားခဲ့တဲ့ စနစ်ကြီးရယ်)*
*(မဲနှိုက်မယ်)*
ဒိုင်းကြီး လည်ပတ်သွားတယ်၊ နှေးသွားတယ်၊ အလင်းတန်းတွေ ထွက်ပေါ်လာခဲ့တယ်။
{ စောင့်ရှောက်ရေး နှလုံးသား (Heart of Nurture) -
ကလေးငယ်များ၏ လိုအပ်ချက်များကို အာရုံခံစားမှု၊ ငြိမ်သက်စေသော ပုံရိပ်နှင့် ကြီးထွားမှု လမ်းညွှန်ချက်တို့ဖြင့် ချက်ချင်း သိရှိပြီး တည်ငြိမ်စေမည်။ ကြိုတင် စောင့်ရှောက်မှုက မတော်တဆမှုများကို ကြိုတင်ခန့်မှန်းပေးမည်ဖြစ်ပြီး၊ သက်တောင့်သက်သာ မှတ်ဉာဏ်က ထာဝရ ယုံကြည်မှုကို ကျန်ရစ်စေမည်။ အသုံးပြုသူသည် ပြည့်စုံသော အုပ်ထိန်းသူအဖြစ် လုပ်ဆောင်နိုင်မည်။ }
ရင်ဘတ်ထဲမှာ နွေးထွေးမှုတွေ ပျံ့လွှင့်သွားခဲ့တယ်။ ကလေးဆရာဝန် တစ်ယောက်အနေနဲ့ ဒါက သူမအတွက် သီးသန့် လက်ဆောင် ရရှိလိုက်သလိုမျိုး ခံစားလိုက်ရတာပါ။ ကြောက်ရွံ့နေတဲ့ ကလေးတွေကို ချော့မော့ပေးတာ၊ မတော်တဆမှုတွေကို မဖြစ်ခင် ကြိုတင် ကာကွယ်ပေးတာ... ဒါတွေက သူမ အမြဲ လုပ်ဆောင်ချင်ခဲ့တဲ့ အရာတွေပါပဲ။
နောက်ဆုံးတစ်စောင်။ နောက်ထပ် ထိပ်တန်းဆုကြီး ရလိမ့်မယ်လို့ မမျှော်လင့်ထားပါဘူး၊ ကံတရားက တော်တော်လေး မျက်နှာသာ ပေးခဲ့ပြီးပြီလေ။
*(မဲနှိုက်မယ်)*
ဒိုင်းကြီး လည်ပတ်သွားပြီး နောက်ဆုံးအကြိမ်အဖြစ် ရွှေရောင် အလင်းတန်းတွေ တောက်ပသွားခဲ့တယ်။
{ သပ်ရပ်ပြေပြစ်သော ရူပကာ (Aesthetic Grace) -
ရုပ်ရည်၊ ဟန်ပန်နှင့် တည်ရှိမှုတို့ကို ဟာမိုနီ ဖြစ်စေမည်။ အသားအရေ တောက်ပမှုက အလှကို ပြည့်စုံစေမည်၊ ဟန်ပန် ပြေပြစ်မှုက ခန္ဓာကိုယ်ကို စနစ်တကျ ဖြစ်စေမည်၊ အကြည့် လွှမ်းမိုးမှုက အာရုံစူးစိုက်မှုကို ဖမ်းစားနိုင်မည်၊ အငွေ့အသက် ပြင်ဆင်မှုက ဆွဲဆောင်မှုကို ထုတ်လွှတ်ပေးမည်ဖြစ်ပြီး၊ လှုပ်ရှားမှု စီးဆင်းမှုက အမူအယာများကို ပိုမို ကောင်းမွန်စေမည်။ အလှအပသည် အားစိုက်စရာမလိုဘဲ သဘာဝအတိုင်း ဆွဲဆောင်မှု ရှိလာမည်။ }
သူမ မသိမသာ သဘောကျစွာ ပြုံးလိုက်မိတယ်။ *(သိလိုက်ပါပြီ။ လက်တွေ့ မကျဆုံးတစ်ခုပေါ့ - အလှအပ တိုးတက်စေတာ သီးသန့်ပဲ။ ငါက ဆရာဝန်ပါ၊ အိုင်ဒေါ မဟုတ်ပါဘူး။ ဒါပေမဲ့... အလကား ရတာဆိုတော့လည်း ခံယူလိုက်ရတာပေါ့)*
အိတ်ဇာတ် စခရင်ကွင်းလေး ခပ်သာသာလေး ပျောက်ကွယ်သွားခဲ့တယ်။ သူမ ထိုင်ခုံပေါ် မှီလိုက်ရင်း နှုတ်ခမ်းပေါ်မှာ လျှို့ဝှက်ဆန်းကြယ်တဲ့ အပြုံးလေး ဖြစ်ပေါ်သွားခဲ့တယ်။
အဲဒီအချိန်မှာပဲ ကားလေးက နှေးကွေးသွားပြီး မြင့်မားလှတဲ့ တံခါးကြီးတွေထဲ ဝင်ရောက်သွားခဲ့တယ်။ သစ်ပင်တွေ ဘေးထွက်ပေးလိုက်ရာမှ ကျယ်ဝန်းလှတဲ့ ခေတ်သစ် ဗီလာအိမ်ကြီး ပေါ်ထွက်လာခဲ့ပြီး နေရောင်ခြည်က ပြတင်းပေါက်ကြီးတွေနဲ့ သပ်သပ်ရပ်ရပ် ပြုပြင်ထားတဲ့ စိုက်ခင်းတွေပေါ် ရိုက်ခတ်နေခဲ့တယ်။
သူတို့ ရောက်ရှိလာခဲ့ပြီ။
အစီအစဉ်၏ ပင်မ အချက်အချာဆီ။ တကယ့် ဇာတ်လမ်း၏ စတင်ရာဆီ။
စူဝမ်ယန် အသက်ကို ဖြေးဖြေးချင်း ရှူသွင်းလိုက်တယ်။
*(ကဲ... ပြည့်စုံတဲ့ ငါးခြောက်မ ဘဝလေးဆီသို့ပေါ့)*
