ဂျူးလီးယန်းသည် ရှေ့သို့ မဆုတ်မနှစ် တိုးကပ်လာသည့် ထိုဂိုက်ကို စိုက်ကြည့်ရင်း ရပ်နေတုန်းမှာပင် ဦးနှောက်ထဲသို့ မည်သည့်နေရာမှန်းမသိသော အသံတစ်ခု အမှတ်မထင် ပေါ်ထွက်လာခဲ့သည်။ အပြင်ဘက်မှ ထွက်ပေါ်လာသည့် အသံမျိုးမဟုတ်ဘဲ မရှိသည့် တံခါးတစ်ခုကို လာရောက်ခေါက်နေသကဲ့သို့ ခေါင်းထဲသို့ တိုက်ရိုက် ရိုက်ခတ်လာခြင်း ဖြစ်၏။
[ဂုဏ်ယူပါတယ် Host။ သင့်ကို အခြားကမ္ဘာသို့ ကူးပြောင်းပေးလိုက်ပါပြီ။ စနစ်ပေါ်လာတာ နည်းနည်းနောက်ကျသွားတဲ့အတွက် တောင်းပန်ပါတယ်]
ဂျူးလီးယန်း ကြက်သေ သေသွားခဲ့သည်။ 'ဒါ ဘာအမှိုက်သရိုက်ကြီးလဲ' ဟု စိတ်ထဲမှ စဲနင်းလိုက်ရင်း ကျောင်းတစ်ကျောင်းလုံး သူ့ကို ပြက်လုံးထုတ် အနိုင်ကျင့်နေသလားဆိုပြီး ခန်းမကြီးထဲ မျက်လုံးဝှေ့ကြည့်လိုက်သည်။ သို့သော် မည်သူမှ တစ်စုံတစ်ရာ ထူးခြားစွာ တုံ့ပြန်ခြင်း မရှိပေ။ ထိုဂိုက်က ပေါက်ကရများ ဆက်လက် ရေရွတ်နေတုန်း ဖြစ်သလို၊ လိုဂန်ကလည်း ဒေါသထွက်နေသည့် ရုပ်ကြီးဖြင့် ရပ်နေဆဲဖြစ်ရာ အခြားသူများမှာ ထိုအသံကို မကြားရဘဲ သူတစ်ယောက်တည်း ကြားရခြင်းဖြစ်ကြောင်း သိလိုက်ရသည်။
[ကျွန်တော်ကတော့ Host ရဲ့ သီးသန့်စနစ် "ဂျီဂျီ" ဖြစ်ပါတယ်။ စနစ်အလုပ်လုပ်ဖို့ စတင်ချိန်ညှိနေရတာကြောင့် ကြန့်ကြာသွားတာကို တောင်းပန်ပါတယ်]
'စနစ် ဟုတ်လား... အေးပေါ့လေ၊ ငါ့ကျမှ စနစ်နဲ့ လာတိုးတာပေါ့' ဂျူးလီးယန်း စိတ်ထဲမှ မဲ့ပြုံး ပြုံးလိုက်မိသည်။ အမှန်တော့ ဒီအချိန်မှာ ဘာပဲဖြစ်လာဖြစ်လာ သူ အံ့ဩမနေတော့ပေ။ ကမ္ဘာပျက်ပြီး လူတစ်ဝက်ကျော် ဇွန်ဘီဖြစ်သွားသည့် ခေတ်ကြီးထဲမှာ သုံးနှစ်တိုင်တိုင် ရှင်သန်ခဲ့ပြီးမှ၊ သူဌေးစိတ္တဇကျောင်းက ဒေါသအိုး စင်တီနယ်တစ်ယောက်နဲ့ စေ့စပ်ထားတဲ့ ခန္ဓာကိုယ်ထဲ ရောက်လာတာတောင် ကျော်ဖြတ်ခဲ့ပြီးပြီပဲ။ အခု ခေါင်းထဲ အသံတစ်သံ တိုးလာတာများ ဘာဆန်းသလဲ။ ပေးသမျှ ရိုက်ချက် အကုန်လက်ခံလိုက်ရုံပေါ့။
“မင်းပြောတာ အခြားသူတွေပါ ကြားရတာလား” ဂျူးလီးယန်းက အခြားသူတစ်ယောက်တည်း စကားပြောနေသည်ဟု ထင်မသွားစေရန် ထိုဂိုက်ဘက်မှ အနည်းငယ် ခေါင်းလွှဲကာ လေထဲသို့ ခပ်တိုးတိုး မေးလိုက်သည်။
[မဟုတ်ပါဘူး။ Host တစ်ယောက်တည်းသာ စနစ်ရဲ့ အသံကို ကြားနိုင်ပါတယ်]
'အေး... တော်သေးတာပေါ့၊ လျှောက်ရှင်းပြနေရမယ့် ဒုက္ခတစ်ခုတော့ လျော့သွားတာပေါ့' သူ စိတ်အေးသွားမိသည်။
ထိုဂိုက်သည် စိတ်တိုင်းမကျသည့် မျက်နှာပေးဖြင့် နောက်ဆုတ်သွားပြီး အမိန့်ပေးခံရသည့် ခွေးတစ်ကောင်လို လိုဂန်၏ ဘေးသို့ ပြန်သွားခဲ့၏။ လိုဂန်ကတော့ ဂျူးလီးယန်းကို လှည့်ပင် မကြည့်တော့ဘဲ ထိုဂိုက်နှင့်အတူ ထွက်ခွာသွားခဲ့သည်။ ဂိုက်က လိုဂန်၏ နားအနားတွင် တစ်ခုခု တိုးတိုးလေး ကပ်ပြောနေသော်လည်း ဂျူးလီးယန်းအတွက်မူ နားထောင်ဖို့ စိတ်မဝင်စားသည့် အမှိုက်စကားများသာ ဖြစ်၏။
ဂျူးလီးယန်း သက်ပြင်းတစ်ချက် ချလိုက်ပြီး အခြားဘက်သို့ ခြေလှမ်းလိုက်သည်။ ခန်းမကြီးထဲမှ ထွက်ကာ မသိသည့် လမ်းကြောင်းအတိုင်း လျှောက်လာခဲ့သော်လည်း ယခုခန္ဓာကိုယ်၏ ကြွက်သား မှတ်ဉာဏ် (Muscle memory) အလိုလို သိနေမှုကြောင့် အခန်းများကို အမှားမရှိ လျှောက်သွားနိုင်ခဲ့၏။ သူသည် တင်းတိမ်စရာ ရာဇဝင်မရှိသည့် အခန်းလွတ်တစ်ခုကို တွေ့သည်အထိ လျှောက်လာခဲ့ပြီး တံခါးပိတ်လိုက်ကာမှ ပုံမှန်အတိုင်း စကားပြန်ပြောလိုက်သည်။
“ကဲ... စနစ်၊ မင်းအကြောင်း မင်း ရှင်းပြစမ်း။ မင်းက ဘာလုပ်ဖို့ ရောက်လာတာလဲ”
[စနစ်ရဲ့ လုပ်ဆောင်ချက်ကတော့ Host အနေနဲ့ ဒီကမ္ဘာမှာ အသက်ရှင်ကျန်ရစ်ပြီး ဘဝကို အောင်မြင်အောင် ကူညီပေးဖို့ ဖြစ်ပါတယ်။ လက်ရှိ ဦးစားပေးတာဝန် - Host ရဲ့ တကယ့် ဂိုက်အဆင့် (True Guide Rank) ကို ဖော်ထုတ်ဖို့ ဖြစ်ပါတယ်]
ဂျူးလီးယန်း မျက်လုံးကလယ်ကလယ် ဖြစ်သွားခဲ့၏။ “တကယ့်အဆင့် ဟုတ်လား... ဘာကို ပြောတာလဲ၊ ငါက F-Class လို့ လူတိုင်းက ပြောနေကြတာလေ”
[မှားယွင်းပါတယ်။ F-Class ဆိုတာ ခန္ဓာကိုယ်ပိုင်ရှင်ဟောင်းရဲ့ မူလအဆင့်သာ ဖြစ်ပါတယ်။ Host ရဲ့ ဝိညာဉ်မှာ ယခင်ကမ္ဘာက ပါလာတဲ့ ထူးခြားစွမ်းအားတွေ ကိန်းဝပ်နေပါတယ်။ ဒီစွမ်းအားတွေကို လက်ရှိအဆင့်ထဲမှာ တွက်ချက်ရသေးခြင်း မရှိပါဘူး]
ဂျူးလီးယန်းသည် ခန်းမထဲရှိ ခမ်းနားလှသော ကုတင်စွန်းတွင် ဖြည်းဖြည်းချင်း ဝင်ထိုင်လိုက်ပြီး စနစ်၏ စကားကို အေးအေးဆေးဆေး စဉ်းစားလိုက်၏။ “ဒါဆို မင်းပြောချင်တာက... ငါ သုံးနှစ်လုံးလုံး ဇွန်ဘီတွေကို သတ်ဖြတ်ခဲ့တာတွေ၊ တံတိုင်းပေါ်မှာ ဒုက္ခခံခဲ့တာတွေက ဒီမှာ အသုံးဝင်တယ်ပေါ့”
[အတည်ပြုပါတယ်။ Host ရဲ့ ရှင်သန်မှု အတွေ့အကြုံ၊ သံမဏိလို ခိုင်မာတဲ့ စိတ်ဓာတ်နဲ့ အန္တရာယ်ရှိတဲ့ သတ္တဝါတွေနဲ့ နီးကပ်စွာ ထိတွေ့ခဲ့ရတဲ့ အတွေ့အကြုံတွေက ဒီကမ္ဘာမှာတော့ အလွန်ရှားပါးတဲ့ ဂိုက်စွမ်းအားလိုင်း (Guide Affinity) အဖြစ် ပြောင်းလဲသွားတာ ဖြစ်ပါတယ်]
“အန္တရာယ်ရှိတဲ့ သတ္တဝါတွေနဲ့ နီးကပ်စွာ ထိတွေ့တယ် ဟုတ်လား...” ဂျူးလီးယန်းက စကားလုံးကို ဖြည်းဖြည်းချင်း ပြန်ရွတ်လိုက်သည်။ “စနစ်... ငါက ဇွန်ဘီတွေကို တိုက်ခဲ့တာကွ၊ ငါ သူတို့နဲ့ မိတ်ဆွေဖွဲ့ခဲ့တာ မဟုတ်ဘူး၊ ခေါင်းကို ဓားနဲ့ ထိုးခွဲခဲ့တာ”
[ပြင်ဆင်ချက်ကို သတ်မှတ်လိုက်ပါပြီ။ ယခင်ကမ္ဘာမှာ အကြမ်းဖက် သတ္တဝါ (Aberration) အမျိုးအစားတွေနဲ့ အချိန်အကြာကြီး ထိတွေ့ခဲ့ရမှုကြောင့် ဒီကမ္ဘာက ဂိုက်တွေမှာ မရှိတဲ့ ခုခံအားနဲ့ အလိုက်သင့် ပြုပြင်နိုင်စွမ်းတွေ ဖြစ်ပေါ်လာတာပါ။ ဒါဟာ အလွန်တန်ဖိုးရှိပါတယ်]
ဂျူးလီးယန်းသည် မျက်နှာကို လက်နှစ်ဖက်ဖြင့် ပွတ်သပ်လိုက်၏။ “ကောင်းလိုက်တာကွာ... ငါ တကယ် မသေရုံတစဉ် မသေမချင်း ဒုက္ခခံခဲ့ရလို့ အသုံးဝင်သွားတယ်ပေါ့။ ပျော်စရာကြီးပါပဲ”
[လတ်တလော စနစ်ရဲ့ အကြံပြုချက် - နောက်တစ်နာရီအကြာမှာ ကျင်းပမယ့် ဝင်ခွင့် စွမ်းရည်စစ်ဆေးပွဲ (Entrance Evaluation) ကို တက်ရောက်ပါ။ Host ရဲ့ တကယ့် စွမ်းအားအဆင့်ကို အဲဒီမှာ ဖော်ထုတ်ပြသနိုင်မှာ ဖြစ်ပါတယ်]
ဂျူးလီးယန်း၏ ခေါင်းက ရုတ်တရက် ထောင်လာခဲ့သည်။ “ခဏလေး... စစ်ဆေးပွဲက ဒီနေ့ ဟုတ်လား၊ ငါ့ကို ဘာလို့ ဘာမှ လာမပြောကြတာလဲ”
[ဒါက မူလပိုင်ရှင်ရဲ့ အမှတ်တရတွေထဲမှာ ရှိပြီးသားပါ။ Host က အမှတ်တရ အားလုံးကို မယူရသေးလို့ပါ]
“အေးပါ... အေးပါ၊ ဟုတ်ပါပြီ” ဂျူးလီးယန်းက ခေါင်းကို လက်ဝါးဖြင့် ဖိထားလိုက်ရာ စောစောက ခေါင်းကိုက်ချင်သလို ခံစားချက်က ပြန်ပေါ်လာခဲ့သည်။ ခန္ဓာကိုယ်သစ်၊ ကမ္ဘာသစ်၊ ခေါင်းထဲမှာ အော်ဟစ်နေသည့် စနစ်အသံ၊ ပြီးတော့ နောက်တစ်နာရီအကြာမှာ “အသုံးမကျတဲ့ F-Class အညံ့စား” ဆိုသည့် သူ့၏ ဟန်ဆောင်မှုကို လေထဲ ပျောက်ကွယ်သွားစေနိုင်မည့် စစ်ဆေးပွဲတစ်ခု။
သူ ရယ်ချင်သွားခဲ့၏။ ကမ္ဘာပျက်စစ်ပွဲတွေ၊ မြို့ရိုးပေါ်က တိုက်ပွဲတွေ၊ ကိုယ်ချစ်ရတဲ့သူတွေ အပိုင်းပိုင်းဆုတ်ဖြဲခံရတာကို မျက်စိရှေ့မှာ ကြည့်ခဲ့ရတာတွေကို ကျော်ဖြတ်ခဲ့ပြီးမှ ယခုမှ လက်တွေ တုန်ချင်လာခဲ့ရသည်။ ကျောင်းဝင်ခွင့် စစ်ဆေးပွဲတစ်ခုကြောင့်တဲ့လေ။
'ကဲ... ထားတော့' သူ ထရပ်လိုက်ပြီး တံတိုင်းပေါ်မှာ တာဝန်မကျမီ အကြောလျှော့သလို ပုခုံးကို လှုပ်ရှားလိုက်သည်။ 'ဒီကမ္ဘာမှာ ငါ့မှာ ဘာစွမ်းအားတွေ ရှိနေလဲဆိုတာ သွားကြည့်ကြတာပေါ့'
[လက်ရှိ ခြိမ်းခြောက်မှုအဆင့်နဲ့ ယှဉ်ရင် Host ရဲ့ ဇွဲသတ္တိ ပမာဏက ပုံမှန်ထက် အဆမတန် မြင့်မားနေပါတယ်။ စနစ်က ထောက်ခံပါတယ်]
“ပါးစပ်ပိတ်ထားစမ်းပါ” ဂျူးလီးယန်းက ခပ်တိုးတိုး ရေရွတ်လိုက်သော်လည်း ဒေါသသံ မပါပေ။ ဒီခန္ဓာကိုယ်ထဲ နိုးထလာပြီးကတည်းက ပထမဆုံးအကြိမ်အဖြစ် သူ၏ မူလစတိုင်အတိုင်း... တည်ငြိမ်မှု၊ ရယ်ချင်စရာကောင်းမှု၊ ဘာပဲလာလာ ရင်ဆိုင်ရန် အသင့်ဖြစ်နေသည့် ခံစားချက်တို့ ပြန်လည် နိုးထလာခဲ့သည်။
သူ အခန်းထဲမှ ထွက်ကာ စစ်ဆေးပွဲ ကျင်းပမည့် ခန်းမဆီသို့ ဦးတည်လိုက်ရာ ခေါင်းထဲမှ စနစ်မှာလည်း ငြိမ်သက်သွားပြီး နောက် ဘာတွေ ဆက်ဖြစ်မလဲဆိုတာကို သူနှင့်ထပ်တူ စိတ်ဝင်စားနေသည့်အလား ခပ်တိုးတိုး မြည်ဟီးလျက် ကျန်ရစ်ခဲ့တော့သည်။
