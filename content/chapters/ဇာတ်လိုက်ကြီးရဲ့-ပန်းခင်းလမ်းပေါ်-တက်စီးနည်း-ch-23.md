ဆူညံပွက်လောရိုက်ခဲ့တဲ့ နေ့တစ်နေ့က အဲ့ဒီလိုပဲ ကုန်လွန်သွားခဲ့တယ်။
မနက်ပိုင်း သင်ခန်းစာပြီးလို့ နာ ယူရီ နဲ့ ထမင်းစားနေတုန်းမှာ ချွဲ ဆူဂျောင်း က ရုတ်တရက် ရောက်လာပြီး ငါတို့ဘေးမှာ ရှက်သွေးမရှိ ထိုင်လိုက်တာမို့ မွန်းလွဲပိုင်း ရောက်သွားခဲ့တယ်။
မွန်းလွဲပိုင်းမှာတော့ စာတွေ့ သင်ခန်းစာတွေ ပြုလုပ်ခဲ့တယ်။
Class F က ကလေး အများစုကတော့ မနက်ပိုင်း သင်ခန်းစာတွေမှာ ပင်ပန်းခဲ့ကြလို့လား မသိ၊ သိုက်သိုက်ဝန်းဝန်း ငိုက်မြည်းနေကြတယ်။
တကယ်ကို အေးချမ်းတဲ့ မြင်ကွင်းပါပဲ။
ဝဘ်နဗ်ဗယ်ရဲ့ ဇာတ်လမ်း သဘောတရားအရ နောက်ပိုင်းကျရင် ငါတို့ဆီ အကြီးမားဆုံး အခက်အခဲကြီးတွေ ကျရောက်လာတော့မယ်ဆိုတာ တကယ်ပင် ယုံနိုင်စရာ မရှိပါဘူး။
<Academy's Commander F-Class> ဆိုတာ အခြေခံအားဖြင့် ကမ္ဘာကြီး ပျက်စီးယိုယွင်းမှုကို တားဆီးတဲ့ ဇာတ်လမ်းတစ်ပုဒ်ပဲ။
ဂိမ်းထဲက ဗီလိန် အပိုဇာတ်ကောင်နေရာကို ကူးပြောင်းလာတဲ့ လိမ်လည်သူ က ဂိမ်းနဲ့ ပတ်သက်တဲ့ အနက်ရှိုင်းဆုံး ဗဟုသုတတွေကို သုံးပြီး 'Flood of Disaster' လို့ ခေါ်တဲ့ မကြာမီ ကျရောက်တော့မယ့် ကမ္ဘာပျက်ကိန်း အဖြစ်အပျက်ကြီးကို တားဆီးဖို့ တက်ကြွစွာ လှုပ်ရှားရတာ။
ဒါကြောင့် နဗ်ဗယ်ရဲ့ ဖြစ်တည်မှုအရ ဆိုရင် 'Flood of Disaster' ဆိုတဲ့ ပျက်စီးခြင်း အဖြစ်အပျက်ကြီးက မကြာမီ အနာဂတ်မှာ မလွှဲမရှောင်သာ ကျရောက်လာတော့မယ်လို့ မြင်ရမယ်။
မူလကတော့ ငါ လိမ်လည်သူ နဲ့ အစပိုင်းမှာပဲ တွဲကပ်နေပြီး နောက်ပိုင်းကျရင် ခွဲထွက်ကာ Flood of Disaster အတွက် ပြင်ဆင်ဖို့ အစီအစဉ် ရှိခဲ့ပေမဲ့ Meta System ပေါ်လာတဲ့အခါမှာတော့ အခြေအနေတွေ ပြောင်းလဲသွားခဲ့တယ်။
Meta System ကို အသုံးပြုခြင်းအားဖြင့် ငါ့ရဲ့ အသုံးဝင်မှုကို တိုးတက်စေနိုင်ပြီး ခေါင်းဆောင်မင်းသားရဲ့ ဘေးမှာ တော်တော်ကြာကြာအထိ ဆက်ရှိနေနိုင်တယ်။
အဲ့ဒီလိုဆိုရင်တော့ ငါ မှတ်မိနေတဲ့ ဇာတ်လမ်းကို တတ်နိုင်သမျှ အသုံးချရတာ ပိုပြီး အကျိုးရှိမှာမို့လို့ ဇာတ်လမ်းရဲ့ အလယ်လောက်အထိ သူ့ဆီမှာပဲ ကပ်တွယ်နေဖို့ ဆုံးဖြတ်လိုက်တယ်။ အဲ့ဒါကြောင့် လတ်တလောမှာတော့ သီးသန့် လှုပ်ရှားမှုတွေ လုပ်ဆောင်တာကို ဆိုင်းငံ့ထားဖို့ ဆုံးဖြတ်လိုက်တာ။
ဒါပေမဲ့ ဘယ်လမ်းကြောင်းကိုပဲ ရွေးချယ်ရွေးချယ်၊ ငါ မဖြစ်မနေ တွေ့ရမယ့် ဇာတ်ကောင် တစ်ယောက်တော့ ရှိတယ်။
'Oracle'။
Oracle ဆိုတာ နဗ်ဗယ်ရဲ့ အလယ်လောက် ရောက်မှ ပထမဆုံး ထွက်ပေါ်လာတဲ့ ဇာတ်ကောင်ပဲ။ သူက လိမ်လည်သူ ဆော့ကစားခဲ့တဲ့ ဂိမ်းရဲ့ ဖန်တီးရှင်ပါလို့ ကြေညာထားသူ။
သူက သီးသန့် ရည်ရွယ်ချက်တစ်ခုအတွက် လိမ်လည်သူ ရဲ့ ဝိညာဉ်ကို တခြားကမ္ဘာကနေ ခေါ်ဆောင်လာခဲ့သူလည်း ဖြစ်တယ်။
Oracle က ငါ့ကိုပါ ဒီဆီ ခေါ်ဆောင်လာခဲ့တာလားလို့ ငါ သံသယဝင်မိတယ်။ အသေးစိတ် သိရှိနိုင်ဖို့အတွက် သူ့ကို မဖြစ်မနေ တွေ့ဆုံရလိမ့်မယ်…
ဘာပဲဖြစ်ဖြစ် အရေးကြီးတာကတော့ Oracle က နဗ်ဗယ်ထဲမှာ လိမ်လည်သူ ဆီ သတင်းအချက်အလက်တွေ ပေးအပ်ပြီး နည်းလမ်းပေါင်းစုံနဲ့ ကူညီပေးခဲ့တဲ့ အရေးပါတဲ့ Support ဇာတ်ကောင် ဖြစ်ခဲ့တယ်ဆိုတာပါပဲ။ လိမ်လည်သူ ဘာလုပ်ရမလဲဆိုတာကို လမ်းညွှန်ပေးတဲ့ အခန်းကဏ္ဍကနေ ပါဝင်ခဲ့တာ။ လမ်းပြတစ်ယောက်လို့ ပြောရမလားပဲ။
အရမ်း သံသယဖြစ်စရာ ကောင်းလွန်းလို့ 'ဒီကောင့် နောက်ကွယ်မှာ တစ်ယောက်ယောက် ရှိနေတာ မဟုတ်ဘူးလား' လို့ တွေးမိခဲ့ကြတဲ့ စာဖတ်သူတွေလည်း မနည်းလှပါဘူး။ ဒါပေမဲ့ ငါ ဖတ်ဖူးသလောက်တော့ သူက ကမ္ဘာကြီး ပျက်စီးမှုကို တားဆီးဖို့ လှုပ်ရှားနေတဲ့ ဆန်းကြယ်တဲ့ ဖြစ်တည်မှုတစ်ခု ပါပဲ။
ဒါကြောင့် ဇာတ်လမ်းအလယ်လောက်အထိတော့ အဆင်ပြေနေဦးမှာပါ။
အကယ်၍ အဆင်မပြေရင်ရော။ ဒါဆိုရင်တော့… ငါ အရင်ဆုံး ထွက်ပြေးရမှာပေါ့။
ဘာပဲဖြစ်ဖြစ် Oracle က သူ့ရဲ့ ရည်မှန်းချက်တွေကို အကောင်အထည်ဖော်ဖို့အတွက် လိမ်လည်သူ နဲ့ လိမ်လည်သူ ရဲ့ ဘေးနားက လူတွေကို ထိန်းချုပ်ချင်တဲ့ အလေ့အထ ရှိတယ်။
ငါ သတိထားမိတာက ဒါပဲ။
ငါက အခု လိမ်လည်သူ ရဲ့ စာချုပ်ချုပ်ထားသူ ဖြစ်နေပြီမို့လို့ Oracle က ငါ့ဆီကိုလည်း တစ်ချိန်ချိန်မှာ ချဉ်းကပ်လာမှာပဲ။ အဲ့ဒီအခါကျရင် ငါက Oracle ရဲ့ စိတ်တိုင်းကျ ထိန်းချုပ်မှုကို ခံယူပြီး လိုချင်တဲ့ ဆုကြေးကို ရယူဖို့ ကြိုးစားရမယ်။
ဘာပဲဖြစ်ဖြစ် Oracle က နဗ်ဗယ်ထဲက 'Battle Tournament' အခမ်းအနား အချိန်လောက်မှာ လိမ်လည်သူ ဆီ ချဉ်းကပ်ခဲ့တာမို့ ငါ့ဆီ ချဉ်းကပ်ချင်တယ်ဆိုရင်လည်း အဲ့ဒီအချိန်မှာပဲ လာလိမ့်မယ်။
“အင်း…”
ဒါတွေအပြင် အခုချက်ချင်း ပြင်ဆင်ထားရမယ့် ပိုပြီး အရေးကြီးတဲ့ ပြဿနာတွေ ရှိသေးတယ်။
နဗ်ဗယ်ရဲ့ ဖြစ်တည်မှုထဲက နောက်ထပ် အဖြစ်အပျက်ကတော့ အလယ်အလတ် စာမေးပွဲကာလမှာ ကျင်းပမယ့် လက်တွေ့စမ်းသပ်မှု တိုက်ခိုက်ရေးပဲ။
Monster တွေ ပေါက်ဖွားထွက်ပေါ်လာတဲ့ Extrude Gate တွေက 'Tower' အနီးမှာပဲ ပွင့်လေ့ရှိကြတာ။ ဒါပေမဲ့ ဘာကြောင့်မှန်းမသိ၊ မကြာမီ ရောက်ရှိတော့မယ့် အလယ်အလတ် စာမေးပွဲကာလမှာ အဲ့ဒီ Extrude Gate က လက်တွေ့စမ်းသပ်မှု ပြုလုပ်မယ့် နေရာမှာ ပွင့်သွားခဲ့တယ်။ သဘာဝအတိုင်းပဲ လက်တွေ့စမ်းသပ်မှုနေရာက ရှုပ်ထွေးသွားခဲ့ပြီး လူအများကြီး သေဆုံး၊ ဒဏ်ရာရခဲ့ကြတယ်။
ဒါပေမဲ့ အဲ့ဒီအချိန် ရောက်လာမယ့်ကာလကို ငါ စောင့်ဆိုင်းရင်း ပြင်ဆင်နေရုံမှအပ အခြားနည်းလမ်း မရှိပါဘူး။ ငါ တင်းတင်းကျပ်ကျပ် လေ့ကျင့်ထားဖို့ လိုအပ်တယ်။
Meta System ကို စစ်ဆေးကြည့်ရအောင်။
ဒါပေမဲ့ မတွေးမခေါ်ဘဲ Meta System ကို ဖွင့်လိုက်မိပြီး တန့်သွားခဲ့တယ်။
Meta Point တွေ လျော့နည်းသွားခဲ့တာပဲ။
မနေ့ညက စစ်ဆေးတုန်းက စုစုပေါင်း Meta Point ၁၃၀ ကျန်နေသေးတာ။
ငါ Level တက်သွားတုန်းက System ရဲ့ Random ခွဲဝေမှု စွမ်းရည်က ငါ လိုချင်တဲ့ Stat တွေပေါ်မှာ ကံကောင်းစွာနဲ့ သက်ရောက်သွားခဲ့တာမို့လို့ Point တွေ အများကြီး ကုန်ခဲ့စရာ မလိုခဲ့ဘူး။
ဒါပေမဲ့ အခု ငါ မြင်နေရတဲ့ Point က ၁၂၀ ပဲ ရှိတော့တယ်။ နည်းပါးတဲ့ ပမာဏ ဖြစ်ပေမဲ့ Point ၁၀ ကတော့ တကယ်ကို လျော့နည်းသွားခဲ့တာပဲ။
ဒါက လျော့ကျသွားလို့ ရတဲ့ အရာမျိုးလား။
ငါ ဇာတ်အိမ် ရှုပ်ထွေးသွားခဲ့တယ်။
Point ၁၀ လောက် ဆုံးရှုံးရတာက ထိခိုက်မှု မဟုတ်ပေမဲ့ ငါ ရရှိထားတဲ့ Meta Point တွေက လျော့ကျသွားနိုင်တယ်ဆိုတဲ့ အချက်ကတော့ သူ့ဟာသူ တုန်လှုပ်စရာပဲ။ ဒါက နောက်ပိုင်း အရေးပေါ်အချိန်မှာ Point တွေကို သုံးစွဲတဲ့အခါ တွက်ချက်မှုတွေ မှားယွင်းသွားနိုင်လို့ပဲ။
ပြဿနာက ဘာလဲ။ ပမာဏလား။ မဟုတ်ဘူး၊ ပမာဏက လုံလောက်နေခဲ့တာ။ အဲ့ဒီမှာ အနုတ်လက္ခဏာ ဆောင်မယ့် အချက် ရှိနိုင်ခြေ နည်းပါတယ်။
ဒါဆို စာဖတ်သူတွေရဲ့ တုံ့ပြန်မှုက ပြဿနာလား။
ငါ မနေ့ညကနေ ဒီနေ့ အပိုင်းအထိ မန့်တွေကို အမြန် ကြည့်ရှုလိုက်တယ်။
အရင် အပိုင်းတွေအထိ အထွေထွေ မန့်တွေမှာ ဘာပြဿနာမှ မရှိခဲ့ပါဘူး။ အဓိကအားဖြင့် ငါ့အပေါ် သဘောထား ကောင်းမွန်တဲ့ အကြောင်းအရာတွေ ဖြစ်ခဲ့တာကြောင့် Meta Point တွေ ပိုတက်လာတာကိုတောင် တွေ့ခဲ့ရတာပါ။
ပြဿနာက ဒီအပိုင်းထဲက မန့်တွေပဲ။ ဒီအပိုင်းထဲက အချို့သော မန့်တွေမှာ အပြောင်းအလဲ ရှိနေခဲ့တယ်။
ငါ အသက်ကို ခပ်ပြင်းပြင်း ရှူသွင်းလိုက်ပြီး အမှောင်ရောင် အရှိန်အဝါတွေ ထွက်ပေါ်နေတဲ့ System စာမျက်နှာပေါ်က မန့်တွေကို ကြည့်လိုက်တယ်။
System က ငါ့ကို အကြောင်းအရင်း ပြောပြဖို့ ကြိုးစားနေပုံရတာ တကယ်ကို သဘောကောင်းလှပါတယ်။ ကျေးဇူးအများကြီး တင်ပါတယ်ဟာ။

ဒါကြောင့်မို့လို့ကို။
ငါ ယုံကြည်မှု ရရှိသွားခဲ့တယ်။
'ငါ' က စိတ်ပျက်စရာ အပြောင်းအလဲ လို့ ခေါ်တဲ့ 'Sweet Potato' ကို ဖြစ်ပေါ်စေခဲ့ပြီး ငါ့ရဲ့ ဇာတ်ကောင်အပေါ် အနုတ်လက္ခဏာဆောင်တဲ့ အကဲဖြတ်မှုတွေကို ဦးတည်စေခဲ့တာပဲ။
အခုချိန်ထိ မန့်တွေထဲက အနုတ်လက္ခဏာ သုံးသပ်ချက်တွေက Coin တွေ၊ Stock တွေကို စနောက်ပြီး ပြောဆိုတာမျိုး သို့မဟုတ် စာဖတ်သူတွေ အချင်းချင်း တိုက်ခိုက်တာ၊ စာရေးသူဆီ ဦးတည်တဲ့ အပြောင်းအလဲတွေအပေါ် မကျေနပ်ချက်တွေ ဖြစ်ခဲ့တာပါ။
ဒီမန့်တွေက ငါ့အပေါ် ဘာသက်ရောက်မှုမှ မရှိခဲ့ပါဘူး။
ဒါပေမဲ့ အခုတော့ 'ကန် နာဟျွန်း' ဆိုတဲ့ ဇာတ်ကောင်အပေါ် မကောင်းတဲ့ ခံစားချက်တွေ ရှိနေကြတာမို့လို့ ငါ့အပေါ် လုံးဝ သက်ရောက်မှု ရှိသွားခဲ့ပြီ။
…အကြောင်းအရင်းကို ပြောနေစရာတောင် မလိုပါဘူး။ ရှင်းရှင်းလင်းလင်း မြင်တွေ့နေရတာမို့လို့ပါ။
ငါ လက်သီးကို တွန့်ကျုံ့ဆုပ်ကိုင်လိုက်တယ်။
မိုက်မဲခဲ့တာပဲ။ ငါ ပိုပြီး အသိတရားရှိရှိ တွေးတော လှုပ်ရှားခဲ့ရမှာကို ခံစားချက်တွေနောက် ပါသွားပြီး အမှားတစ်ခု လုပ်မိခဲ့တယ်။
မိဘမဲ့ဂေဟာက စာဖတ်သူတွေရဲ့ အနုတ်လက္ခဏာ အချက်အဖြစ် ဖော်ပြခြင်း ခံလိုက်ရတာမို့လို့ အဲ့ဒီအကြောင်း ထုတ်ပြောတိုင်း Point တွေ ဆက်တိုက် ဖြတ်တောက်ခံရဖို့ ရာခိုင်နှုန်း ပိုများနေတယ်။
ဒီအကဲဖြတ်မှုကို ပြောင်းလဲပစ်နိုင်မယ့် အကြောင်းပြချက် မရှိမချင်း မိဘမဲ့ဂေဟာ၊ ဆရာမ နဲ့ ငါတို့ ကလေးတွေနဲ့ ပတ်သက်တဲ့ အကြောင်းအရာ အားလုံးကို ထုတ်ဖော်ပြသခြင်း မပြုဖို့ တားမြစ်ထားတယ်လို့ ပြောလို့ရတယ်။
အေးစက်စွာ သုံးသပ်ရရင်တော့ ဒါက မှန်ကန်တဲ့ ဆုံးဖြတ်ချက်ပါပဲ။
ဒါပေမဲ့…
ငါ ဒေါသထွက်မိတယ်။
ငါ ရရှိခဲ့တာထက် အများကြီး လျော့နည်းပြီး ငါ အချစ်ရဆုံး လူတွေကို ပြန်လည် ပေးဆပ်ခဲ့တဲ့ ငါ့ရဲ့ လှုပ်ရှားမှုတွေကို 'Sweet Potato' အဖြစ် သတ်မှတ်ပစ်လိုက်ကြတာကို တွေ့ရတာ တကယ်ကို စိတ်တိုစရာ ကောင်းလွန်းလှပါတယ်။
ငါ မြတ်နိုးရတဲ့ အရာတွေက ငါ့ကြောင့် သူစိမ်းတွေရဲ့ မတရား စွပ်စွဲပြစ်တင်မှုကို ခံနေရလို့ ငါ တကယ်ကို ဒေါသထွက်ခဲ့ရတာ။
ရုတ်တရက် ငါ့ရဲ့ လက်ဝါးတွေ စိန်းစိန်းမြမြ ခံစားလိုက်ရတာမို့ လက်သီးကို ဖြန့်လိုက်တဲ့အခါ ထင်ရှားတဲ့ လက်သည်းရာတွေကို တွေ့လိုက်ရတယ်။
ငါ ဘာလုပ်ရမလဲ။
ကျန်ရှိနေတဲ့ Meta Point တွေကို မကုန်ခန်းခင် အခုချက်ချင်း သုံးပစ်လိုက်လို့ ရပေမဲ့ အဲ့ဒါက ရှေ့တစ်လှမ်းပဲ မြင်နိုင်တဲ့သူတွေ လုပ်မယ့် အလုပ်မျိုးပါ။
ငါ့ဘေးမှာ လူတိုင်းရဲ့ Stat တွေကို ချက်ချင်း မြင်နိုင်တဲ့ 'Insight Eye' ကို ပိုင်ဆိုင်ထားတဲ့ လိမ်လည်သူ က အမြဲတမ်း ရှိနေတာ။ Monster တွေကို မသတ်ခဲ့ဘဲ Stat တွေ အပြောင်းအလဲ ဖြစ်သွားရင် ဆန်းကြယ်နေပါလိမ့်မယ်။
ဒါ့အပြင် Point တွေကို တစ်ကြိမ်တည်း အများကြီး သုံးစွဲလိုက်တာက 'ပါရမီပါတဲ့ တိုးတက်မှုရှိသူ ဇာတ်ကောင်' အဖြစ် အခြေစိုက်မယ့် အစီအစဉ်ကိုလည်း နှောင့်ယှက်ရာ ရောက်ပါတယ်။
ပထမဆုံးအနေနဲ့ Point တွေ အများကြီး မဖြတ်တောက်ခံရသေးပါဘူး။ ဒါကြောင့် အခြေအနေကို စောင့်ကြည့်ရင်း အလယ်အလတ် စာမေးပွဲ မတိုင်မီ ပမာဏနဲ့ ဂုဏ်သတင်းကို တတ်နိုင်သမျှ ကောင်းမွန်အောင် ထိန်းသိမ်းပြီး Point တွေကို ရယူရမယ်။
ရပါတယ်။
ငါ့ရဲ့ မိဘမဲ့ဂေဟာက လူတွေအတွက်ဆိုရင် ငါ ဘာမဆို လုပ်နိုင်တယ်။
လိမ်လည်သူ တွေကို အမြဲတမ်း ဦးစားပေးပြီး 'Sweet Potato' ဆိုတာမျိုး လုံးဝ မပေးမယ့် ဇာတ်ကောင်အဖြစ် သရုပ်ဆောင်ကြစို့။ စာဖတ်သူတွေ လိုချင်သမျှ၊ သူတို့ လိုချင်သလောက် ပေးလိုက်မယ်။
ငါ့ကိုယ်ငါ အဲ့ဒီလို ပြောလိုက်ပေမဲ့ ဘာကြောင့်မှန်းမသိ ငါ့ရင်ထဲမှာ စိန်းစိန်းမြမြ ခံစားလိုက်ရတယ်။
ဒါက ငါ့ရဲ့ လက်ချောင်းထိပ်မှာ စူးဝင်နေတဲ့ ဆူးတစ်ချောင်းလိုမျိုး ဝေဝါးပြီး အကြာကြီး မေ့ပစ်လို့ မရနိုင်တဲ့ နာကျင်မှုတစ်ခုပါပဲ။
