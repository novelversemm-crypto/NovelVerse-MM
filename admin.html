User Management

Website မှာ စာရင်းသွင်းထားတဲ့ User များ၊ Coin လက်ကျန်နဲ့ Account အခြေအနေတွေကို စီမံရန်။

User စာရင်းများကို Backend ချိတ်ဆက်ပြီးမှ ပြသပါမည်။ User ရဲ့ Password သို့မဟုတ် PIN အစစ်ကို Admin Panel မှာ မပြသသင့်ပါ။
User ID Username Email Coin Balance Joined Date Status Action
User Data များကို Backend ချိတ်ဆက်ပြီးမှ ပြသပါမည်။

Payment Approval

KBZPay / WavePay မှတစ်ဆင့် Coin ဝယ်ယူထားသော Order များကို စစ်ဆေးအတည်ပြုရန်။

ငွေလွှဲ Screenshot တစ်ခုတည်းကို မယုံကြည်ပါနှင့်။ ငွေလက်ခံရရှိမှုကို ကိုယ်တိုင်စစ်ဆေးပြီးမှ Approve လုပ်ပါ။ Approve လုပ်ပြီးမှသာ User ရဲ့ Coin Balance တိုးရပါမည်။
Order ID User Payment Method Amount (MMK) Coin Package Submitted Date Status Action
Payment Request များကို Backend ချိတ်ဆက်ပြီးမှ ပြသပါမည်။

Coin Transactions

User များ၏ Coin ဝယ်ယူမှု၊ Chapter ဝယ်ယူမှုနဲ့ Coin ပြောင်းလဲမှုမှတ်တမ်းများ။

Transaction ID User Type Coin Change Balance After Reference Date
Transaction မှတ်တမ်းများကို Backend ချိတ်ဆက်ပြီးမှ ပြသပါမည်။

User Coin Adjustment

လိုအပ်ပါက User တစ်ဦးချင်းစီ၏ Coin ကို Admin မှ ပြင်ဆင်ပေးနိုင်ရန်။ လုပ်ဆောင်မှုတိုင်းကို Transaction မှတ်တမ်းအဖြစ် သိမ်းဆည်းရပါမည်။

Paid Chapter Settings

Admin Settings

Website ရဲ့ Payment နဲ့ Coin စနစ်ဆိုင်ရာ သတ်မှတ်ချက်များ။

အောက်ပါ Setting များသည် UI အတွက်သာ ဖြစ်ပါသေးသည်။ Backend ချိတ်ဆက်ပြီးမှ အမှန်တကယ် သိမ်းဆည်းနိုင်ပါမည်။

Payment Account Information

Coin System Information

Security Information

Admin Panel ကို URL မသိသူများ မဝင်နိုင်အောင် Link ဖျောက်ထားရုံဖြင့် လုံခြုံမှု မရှိပါ။ Backend မှာ Admin Authentication နဲ့ Permission စစ်ဆေးရန် လိုအပ်ပါသည်။

  • Admin API များကို Server-side Authentication ဖြင့် ကာကွယ်ပါ။
  • GitHub Token ကို Public JavaScript ထဲတွင် မထည့်ပါနှင့်။
  • User Password / PIN ကို Plain Text အဖြစ် မသိမ်းပါနှင့်။
  • Coin ပြောင်းလဲမှုတိုင်းကို Transaction Log သိမ်းပါ။
  • Payment တစ်ခုကို နှစ်ကြိမ် Approve မဖြစ်စေရန် Backend မှ စစ်ဆေးပါ။
