How to Top Up

  1. 1
    ငွေလွှဲပါ

    မိမိဝယ်ယူလိုသော Coin Package ဈေးနှုန်းအတိုင်း KBZPay သို့မဟုတ် WavePay မှ ငွေလွှဲပါ။

  2. 2
    Payment Screenshot ပို့ပါ

    ငွေလွှဲပြီးပါက ငွေလွှဲအောင်မြင်ကြောင်း Screenshot ကို Admin Telegram သို့ ပို့ပေးပါ။

  3. 3
    Promo Code ရယူပြီး Redeem လုပ်ပါ

    Admin မှ ငွေလွှဲမှုကို စစ်ဆေးပြီးနောက် သင့်ငွေပမာဏအတွက် Promo Code ပေးပါမယ်။ ရရှိလာသော Code ကို အောက်တွင် ထည့်သွင်းပြီး Coin ရယူနိုင်ပါတယ်။

Send Payment Screenshot to Admin

Redeem Promo Code

Admin ထံမှ ရရှိထားသော Promo Code ကို ထည့်သွင်းပါ။

Promo Code တစ်ခုကို တစ်ကြိမ်သာ အသုံးပြုနိုင်ပါတယ်။

Important Notice

  • ငွေမလွှဲမီ Payment Account နှင့် ငွေပမာဏကို သေချာစစ်ဆေးပါ။
  • ငွေလွှဲပြီးနောက် Payment Screenshot ကို Admin Telegram သို့ ပို့ပေးပါ။
  • Admin မှ ငွေလွှဲမှုကို အတည်ပြုပြီးမှ Promo Code ရရှိပါမယ်။
  • Promo Code ကို တစ်ကြိမ်သာ အသုံးပြုနိုင်ပါတယ်။
  • Coin ရရှိရန် Admin ပေးထားသော Promo Code ကို Redeem လုပ်ပေးရပါမယ်။
