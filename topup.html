Coin Packages

သင်ဝယ်ယူလိုသော Coin Package ကို ရွေးချယ်ပါ။

Package ဈေးနှုန်းများကို နောက်ပိုင်းတွင် Admin Settings မှ ပြောင်းလဲနိုင်အောင် ချိတ်ဆက်ပေးပါမယ်။

အထက်ပါ Account သို့ သတ်မှတ်ထားသော ငွေပမာဏကို လွှဲပေးပြီး ငွေလွှဲအထောက်အထားကို အောက်တွင် တင်ပေးပါ။

Payment Confirmation

ငွေလွှဲပြီးပါက အောက်ပါအချက်အလက်များကို ဖြည့်သွင်းပေးပါ။

KBZPay / WavePay မှ ရရှိသော Transaction ID ကို ထည့်ပါ။
ငွေလွှဲအောင်မြင်ကြောင်း ပြသသည့် Screenshot ကို တင်ပေးပါ။ JPG, PNG, WEBP ပုံများကိုသာ လက်ခံပါမည်။

Redeem Code

သင့်မှာရှိတဲ့ Top-up Code ကို အသုံးပြုပြီး Coin ရယူပါ။

Have a Top-up Code?

ရရှိထားသော Code ကို ထည့်သွင်းပြီး Coin များ ရယူနိုင်ပါတယ်။

Code တစ်ခုကို တစ်ကြိမ်သာ အသုံးပြုနိုင်ပါသည်။

Transaction History

သင့် Coin လုပ်ဆောင်မှုမှတ်တမ်းများ။

မှတ်တမ်းမရှိသေးပါ

သင့်ရဲ့ Coin Transaction များကို ဒီနေရာမှာ ပြသပေးပါမယ်။

သိထားသင့်သော အချက်များ

  • Payment တင်သွင်းပြီးနောက် Admin မှ စစ်ဆေးအတည်ပြုပေးပါမည်။
  • Payment အတည်ပြုပြီးမှသာ သင့် Account ထဲသို့ Coin များ ဝင်ရောက်ပါမည်။
  • Transaction ID နှင့် Screenshot မှန်ကန်စွာ တင်သွင်းပေးပါ။
  • Payment တစ်ခုတည်းကို ထပ်ခါတလဲလဲ တင်သွင်းခြင်း မပြုလုပ်ပါနှင့်။
  • Coin ဖြင့် ဝယ်ယူပြီးသော Paid Chapter များ၏ အခြေအနေကို သင့် Account မှာ စစ်ဆေးနိုင်ပါသည်။
