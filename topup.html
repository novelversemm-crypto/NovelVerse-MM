How to Top Up

  1. 1
    Package ရွေးချယ်ပါ

    အထက်ပါ Coin Package များထဲမှ တစ်ခုကို ရွေးပါ။

  2. 2
    ငွေလွှဲပါ

    KBZPay သို့မဟုတ် WavePay ဖြင့် ရွေးချယ်ထားသော Package ဈေးနှုန်းအတိုင်း ငွေလွှဲပါ။

  3. 3
    Screenshot ပို့ပါ

    ငွေလွှဲပြီးပါက Payment Screenshot နှင့် ရွေးချယ်ထားသော Package ကို Admin Telegram သို့ ပို့ပါ။

  4. 4
    Promo Code ရယူပါ

    Admin မှ ငွေလွှဲမှုကို စစ်ဆေးပြီးနောက် သင့် Package အတွက် Promo Code ပေးပါမယ်။

  5. 5
    Promo Code Redeem လုပ်ပါ

    အောက်ပါ Redeem နေရာတွင် Code ထည့်ပြီး Coin လက်ခံရယူပါ။

Contact Admin on Telegram

Redeem Promo Code

Admin မှ ရရှိထားသော Promo Code ကို ထည့်သွင်းပါ။

Promo Code တစ်ခုကို တစ်ကြိမ်သာ အသုံးပြုနိုင်ပါတယ်။

Important Notice

  • ငွေမလွှဲမီ Package ဈေးနှုန်းကို သေချာစစ်ဆေးပါ။
  • ငွေလွှဲ Screenshot ကို Admin ထံ ပေးပို့ပါ။
  • Promo Code ကို အခြားသူများနှင့် မမျှဝေပါနှင့်။
  • အသုံးပြုပြီးသော Promo Code ကို ထပ်မံအသုံးပြု၍ မရပါ။
  • Coin လက်ကျန်ကို Backend မှ အတည်ပြုထားသော Balance အတိုင်းသာ ပြသပါမည်။
